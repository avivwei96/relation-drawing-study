Each screen shows a short description and two generated images, A and B, made from the same starting noise by two different models. Which model made which image is hidden and changes from pair to pair.

  • Relation holds: the first object is placed as described relative to the second (left of, right of, above, below). Judge only the placement.
  • Looks better: overall image quality: sharper, more realistic, fewer distortions. Ignore the description.
  • The model is still in training, so objects can look rough: a duck may be just a yellow blob. Judge roughly.
  • You may skip a question you cannot judge and still press Next.

You will see about 27 pairs, which takes around 7 minutes. No sign-in is needed. Your answers are sent automatically when you finish. Progress is kept in this browser, so you can pause and come back on the same device.
